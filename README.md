# Крупномасштабная математика

Популярная лекция А. А. Арутюнова (ВШМ МФТИ) для школьников: квазиизометрии, концы графов, рост, неподвижные точки.

**Смотреть:** https://forodirch.github.io/Coarse-Lecture-HSM/

Управление: → / ← или щелчок — слайды, `F` — полный экран, `H` — подсказка. Презентация — один автономный HTML-файл, работает без интернета.

## Сборка

```
npm install
npm run build        # → dist/lecture.html
```

Скопируйте `dist/lecture.html` в корень репозитория под именем `index.html` — это и есть опубликованная версия.

## Устройство

- `src/slides.html` — текст слайдов; формулы в `$…$` и `$$…$$` (KaTeX, рендерятся при сборке).
- `src/anim/*.js` — анимации (canvas/SVG), подключаются через `data-fig="имя"`.
- `src/engine.js` — переключение слайдов и зацикленные анимации «туда и обратно».
- `src/style.css` — оформление.
- `build.mjs` — сборка: встраивает KaTeX, шрифт PT Sans, стили и скрипты в один файл.
- `tools/shots.py` — скриншоты слайдов (Playwright) для проверки.
